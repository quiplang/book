# Introduction

> **Note:** This book is still a work in progress. It may not explain all the features of the language.

If you are reading this you probably want to learn about Quip. Well... that's the best place for it. The Quip programming language is a general-purpose programming language that allows you to focus on *making* software, which is reliable.
These days its rather hard to determinate whether a programming language is High/Low-Level becuase of different paradigms, approaches and abstraction levels. So Quip doesn't try to fit into any of these categories. 
It allows for accessing low-level system resources and memory directly, while still providing a high-level, safe abstraction. Whether you're a beginner or an experienced programmer, Quip has something to offer.
